# Bewerbungsdokumente

Lege die PDF-Dateien direkt in diesen Ordner. Sie erscheinen nur nach dem Login auf der Webseite.

- Zeugnisse: `zeugnisse.pdf` oder mehrere Dateien wie `zeugnisse-1.pdf`
- ÜK: `uek-1.pdf`, `uek-2.pdf` oder Dateien, die mit `KNW` beginnen (zum Beispiel `KNW106_Eberhardt_Richard.pdf`)
- Arbeitszeugnisse: `arbeitszeugnisse.pdf` oder mehrere Dateien wie `arbeitszeugnisse-1.pdf`
- Lebenslauf: `lebenslauf.pdf`

Nach dem Hinzufügen erscheinen automatisch die Buttons zum Ansehen und Herunterladen.
